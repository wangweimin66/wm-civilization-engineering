# Decision Engine (Core System)

## 1. Purpose（目的）

Transform the Civilization Engineering System into a semi-automated decision engine.

---

## 2. Input Layer（输入层）

Required input:

- Country / Region
- Market type
- Objective (e.g. trade, investment)

---

## 3. Processing Pipeline（处理流程）

### Step 1: Cognition Mapping
→ Identify civilization type

---

### Step 2: Node Identification
→ Map key nodes:
- Power
- Economic
- Cultural
- External

---

### Step 3: Scoring
→ Apply evaluation model:
- Stability
- Control
- Economic
- Culture
- External

---

### Step 4: Classification

Based on score:

- A = Deep Entry
- B = Controlled Entry
- C = Test Only
- D = Avoid

---

### Step 5: Strategy Generation

Auto-match strategy:

| Level | Strategy |
|------|----------|
| A | Build core node |
| B | Enter economic nodes |
| C | Short-term operation |
| D | No entry |

---

### Step 6: Execution Template

Output:

- Entry mode
- Target node
- Risk control
- Exit plan

---

## 4. Output Format（输出格式）

Standard output:

- Country Profile
- Score Table
- Risk Level
- Strategy
- Execution Plan

---

## 5. Core Logic（核心逻辑）

High Control + Medium External → Best Entry Zone  
Low Control + High External → High Risk Zone  

---

## 6. Future Upgrade（升级方向）

- AI integration
- Automated scoring
- Data-driven inputs
