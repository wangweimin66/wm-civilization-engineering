# M-01 Node System

## 1. Definition（定义）

Node（结）是文明系统中的基本结构单元，代表资源、权力、信息与人口的汇聚点与控制点。

Node 并非“点”，而是：
- 汇聚结构（Aggregation）
- 控制结构（Control）
- 连接结构（Connection）

---

## 2. Types of Nodes（结的类型）

### 2.1 Power Node（权力结）
- 政府
- 军事
- 地方控制集团

👉 作用：维持秩序 / 控制区域

---

### 2.2 Economic Node（经济结）
- 市场
- 企业
- 供应链核心

👉 作用：资源分配 / 财富生成

---

### 2.3 Cultural Node（文化结）
- 教育系统
- 媒体
- 宗教

👉 作用：塑造认知 / 统一叙事

---

### 2.4 Information Node（信息结）
- 网络平台
- 通讯系统
- 数据中心

👉 作用：信息流控制

---

### 2.5 External Node（外部结）
- 外资
- 国际组织
- 跨国势力

👉 作用：输入或干预系统

---

## 3. Node Structure（结构）

一个文明可以被视为：

> Node Network（结网络）

核心特征：

- 中心结（Central Node）
- 次级结（Sub Nodes）
- 边缘结（Peripheral Nodes）

---

## 4. Node Dynamics（运作机制）

### 4.1 Flow（流动）
- 资源流
- 信息流
- 权力流

---

### 4.2 Control（控制）
Node 之间存在控制关系：

- 上级控制
- 横向竞争
- 外部干预

---

### 4.3 Stability（稳定性）

系统稳定取决于：

- 中心结是否稳固
- 连接是否顺畅
- 是否存在断裂

---

## 5. Failure Modes（失效模式）

当出现以下情况：

- 关键 Node 崩溃
- 信息流断裂
- 外部 Node 入侵

👉 系统将出现：
- 动荡
- 分裂
- 重组

---

## 6. Application（应用）

Node System 可用于：

### 6.1 国家分析
识别：
- 核心控制结构
- 真实权力所在

---

### 6.2 商业策略
选择：
- 进入哪个 Node
- 控制哪个 Node

---

### 6.3 风险评估
判断：
- 哪些 Node 不稳定
- 哪些区域可操作

---
