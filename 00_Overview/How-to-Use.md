# How to Use This System

## 1. Purpose（目的）

This document explains how to use the Civilization Engineering System to analyze a country, region, or market and generate actionable strategies.

---

## 2. Input（输入）

Start with a target:

- A country (e.g. Vietnam)
- A region
- A market

---

## 3. Step-by-Step Process（操作流程）

---

### Step 1: Cognition Mapping（认知映射）

Identify the civilization attributes:

- Civilization type
- Cultural structure
- Historical background

---

### Step 2: Model Analysis（模型分析）

Apply core models:

- Node System
  - Identify key Nodes (power, economic, cultural)
- Flow Analysis
  - Resource flow
  - Information flow

---

### Step 3: Judgement（判定）

Use the evaluation model:

- Stability
- Control Power
- Economic Structure
- Cultural Cohesion
- External Influence

Output:
- Scores
- Risk level

---

### Step 4: Strategy Generation（策略生成）

Based on judgement:

- Enter / Not enter
- Entry mode (economic / information / population)
- Node targeting

---

### Step 5: Execution Planning（执行规划）

Define:

- Action steps
- Resource allocation
- Risk control
- Exit strategy

---

## 4. Output（输出）

The system should generate:

- Country evaluation
- Risk profile
- Entry strategy
- Execution plan

---

## 5. Example Workflow（示例流程）

Input: Vietnam

↓

Node Analysis:
- Strong economic nodes
- Moderate control power

↓

Evaluation:
- Stability: Medium-High
- Risk: B

↓

Strategy:
- Enter via economic nodes
- Focus on trade and supply chain

---

## 6. Key Principles（关键原则）

1. Always start from models, not opinions  
2. Avoid direct political nodes  
3. Focus on controllable structures  
4. Design exit before entry  

---

## 7. System Usage Scope（适用范围）

- Country analysis  
- Market entry decision  
- Risk assessment  
- Strategic planning
