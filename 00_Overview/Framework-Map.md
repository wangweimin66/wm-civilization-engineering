# Civilization Engineering Framework Map

## 1. System Overview（系统总览）

This system is designed as a Civilization Control OS, transforming abstract knowledge into actionable strategies.

Core Logic:

Cognition → Models → Judgement → Strategy → Execution

---

## 2. Core Decision Pipeline（核心决策链）

### 2.1 Cognition Layer（认知层）
Defines the fundamental understanding of civilization.

- Civilization Types
- Cultural Structures
- Macro Definitions

---

### 2.2 Model Layer（模型层）
Builds abstract structures to describe reality.

- Node System (M-01)
- Power Flow
- Resource Structure

---

### 2.3 Judgement Layer（判定层）
Transforms models into measurable evaluation.

- Country Evaluation Model (J-01)
- Risk Assessment
- Stability Index

---

### 2.4 Strategy Layer（策略层）
Generates actionable strategies.

- Market Entry Strategy (S-01)
- Resource Capture
- Influence Building

---

### 2.5 Execution Layer（执行层）
Converts strategy into real-world actions.

- Business Models
- Operational Plans
- Risk Control

---
